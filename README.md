## 📖 Overview of Exercises

All exercises are implemented in [`lib/main.dart`](file:///D:/year%203/Term1/Mobile/W5/homework/lib/main.dart):

| Exercise | Focus | Description |
| :--- | :--- | :--- |
| **Exercise 1** | Text & Scaffold | Basic colored background scaffold with centered custom text. |
| **Exercise 2** | Containers & Spacing | Nested containers demonstrating margins, padding, and `BoxDecoration` with border radius. |
| **Exercise 3** | Column Layout | Vertical arrangement of styled containers with different color shades (`Colors.blue`). |
| **Exercise 4** | Rows, Columns & Expanded | Complex layout practicing `Expanded`, `Row`, `Column`, and `SizedBox` spacing. |
| **Exercise 5** | UI Screen Mockup | Complete layout with a top header banner ("Welcome !"), hobby cards ("Soccer" & "Flutter"), and custom bottom navigation bar. |

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- Compatible IDE (VS Code, Android Studio) or Flutter CLI

### Installation & Run

1. Clone or navigate to the repository folder:
   ```bash
   git clone https://github.com/dina-seng/hw-mobile-w45.git
   cd hw-mobile-w45
   ```

2. Get project dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```

> **Note**: By default, **Exercise 5** is active in `lib/main.dart`. To run other exercises, comment out Exercise 5 and uncomment the desired exercise's `main()` function.
